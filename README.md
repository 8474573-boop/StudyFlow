# Task Tracker

Трекер задач з Kanban-дошкою: статуси, пріоритети, дедлайни, теги, фільтри, статистика й експорт у CSV.

![screenshot](docs/screenshot.png)

## Запуск

Потрібен Node.js (версія LTS).

```bash
npm install      # встановити залежності
npm run seed     # додати демо-задачі
npm start        # запустити сервер → http://localhost:3000
npm test         # перевірити ядро
```

## Можливості

- Створення, редагування (подвійний клік по назві) і видалення задач
- Три статуси: To Do → In Progress → Done, зміна статусу перетягуванням картки
- Пріоритет (низький / середній / високий) і дедлайн; прострочені задачі підсвічуються червоним
- Теги, пошук за назвою, фільтр за тегом, фільтр «лише прострочені»
- Статистика і експорт усіх задач у CSV (відкривається в Excel)
- Дані зберігаються у файлі `data/tasks.json` і не зникають після перезапуску

## Модель даних

```js
{
  id: "uuid",                                  // унікальний, не залежить від позиції в списку
  title: "Лаба 4 з ООП",                       // обов'язкове, 1–200 символів
  status: "todo" | "in_progress" | "done",
  priority: "low" | "med" | "high",            // за замовчуванням "med"
  deadline: "2026-11-30" | null,               // необов'язкове
  tags: ["університет"],
  createdAt: "2026-11-23T12:00:00.000Z",       // час у UTC, формат ISO 8601
  updatedAt: "2026-11-23T12:00:00.000Z"
}
```

## Як зберігаються дані

Спочатку пишемо у тимчасовий файл `tasks.json.tmp`, потім перейменовуємо його в `tasks.json`.
Перейменування атомарне, тому файл не зіпсується, навіть якщо програму вбити посеред запису.
Якщо файл пошкодили вручну, програма зберігає його копію в `tasks.json.broken` і стартує з порожнім списком.

## API

| Метод | Шлях | Опис |
|---|---|---|
| GET | `/api/tasks?status=&priority=&tag=&q=&overdue=1` | список із фільтрами |
| POST | `/api/tasks` | створити задачу |
| PATCH | `/api/tasks/:id` | змінити поля або статус |
| DELETE | `/api/tasks/:id` | видалити |
| GET | `/api/stats` | статистика |
| GET | `/api/export.csv` | експорт у CSV |

Некоректні дані → `400`, неіснуюча задача → `404`.

## Структура

```
src/storage.js      — збереження у файл
src/validation.js   — перевірка вхідних даних
src/taskService.js  — логіка задач
src/server.js       — веб-сервер і API
public/             — сторінка з Kanban-дошкою
seed.js, test.js    — демо-дані і тести
```
